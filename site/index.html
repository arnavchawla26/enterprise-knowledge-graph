enterprise-knowledge-graph

A governed knowledge graph over one small enterprise, built so that an agent gets trusted, provenance-backed context instead of raw tables.

Repository on GitHub README reports/ (the source of every number here) docs/
Realthe per-drive telemetry summary and failure dates (Backblaze Hard Drive Data 2026 Q2), the 30-day failure probability from the sibling project's model, the declared pipeline, and the column metadata read from Postgres and DuckDB.
Generatedaccounts, sites, assets, cases, dispatches, parts, suppliers, runbooks, the data products, jobs, lineage rows and the 300-row query log, all from the sibling project's seeded generator with ground truth. The mess the resolver removes was put there on purpose, so its numbers are a ceiling.
What is live here. This page is static: scripts/build_site.py reads reports/ and docs/LINEAGE.md and writes the JSON the charts draw from. Neo4j, Elasticsearch, Kibana and the context API do not run on Vercel. From a clone, make up load resolve lineage gds eval trust rebuilds everything, and make eval reruns the text-to-Cypher sets from the committed cache with zero model calls.
